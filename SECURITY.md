# Security Policy

## Supported Versions

celq supports one minor version release at a time both for bug and
security fixes. For example, if the most recent release is 0.3.1 the 0.3.x
release series is currently supported. If you ask for support for
older versions, we will tell you to update first.

## Reporting a Vulnerability

To report vulnerabilities you can privately report a potential security issue
via the Github security vulnerabilities feature. This can be done here:

https://github.com/IvanIsCoding/celq/security/advisories

Please do **not** open a public issue about a potential security vulnerability.

You can find more details on the security vulnerability feature in the Github
documentation here:

https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability
